# Interactive Polls Platform

Курсовой проект:
«Клиентская часть веб-платформы для проведения интерактивных опросов и голосований».

## Стек

- HTML5
- CSS3
- JavaScript (ES6+)
- Vite
- Node.js
- Express

## Возможности

- Просмотр опросов
- Голосование
- Создание опросов
- Фильтрация и поиск
- SPA роутинг
- Личный кабинет
- localStorage
- Mock API
