# Анализ предметной области

## Тема проекта

«Клиентская часть веб-платформы для проведения интерактивных опросов и голосований».

---

# Анализ предметной области

Интерактивные опросы используются для:

- сбора мнений пользователей;
- проведения голосований;
- аналитики;
- маркетинговых исследований;
- образовательных тестирований;
- оценки качества услуг.

Современные платформы голосований позволяют быстро создавать опросы, собирать результаты и визуализировать статистику.

Основные требования к подобным системам:

- удобный интерфейс;
- адаптивность;
- высокая скорость работы;
- простота участия в голосовании;
- наглядное отображение результатов;
- фильтрация и поиск;
- безопасность пользовательских данных.

---

# Анализ аналогов

## 1. Google Forms

Преимущества:

- простой интерфейс;
- удобное создание форм;
- интеграция с Google Workspace.

Недостатки:

- ограниченная кастомизация интерфейса;
- слабая визуализация результатов.

---

## 2. StrawPoll

Преимущества:

- быстрые голосования;
- минималистичный интерфейс;
- удобство использования.

Недостатки:

- ограниченный функционал;
- отсутствует полноценный личный кабинет.

---

## 3. SurveyMonkey

Преимущества:

- мощная аналитика;
- гибкие настройки;
- корпоративный функционал.

Недостатки:

- сложность интерфейса;
- часть возможностей доступна только по подписке.

---

# Цель работы

Разработка клиентской части SPA веб-платформы для создания интерактивных опросов и проведения голосований.

---

# Задачи проекта

## Основные задачи

1. Реализовать SPA-приложение на JavaScript без использования frontend-фреймворков.
2. Создать клиентский роутинг.
3. Реализовать работу с mock API.
4. Реализовать создание и прохождение опросов.
5. Добавить хранение данных в localStorage.
6. Реализовать адаптивный интерфейс.
7. Добавить визуализацию результатов голосования.
8. Реализовать валидацию форм.
9. Обеспечить базовую доступность интерфейса (a11y).
10. Подготовить документацию и сценарии тестирования.

---

# Ожидаемый результат

В результате разработки должно быть получено SPA-приложение, позволяющее:

- просматривать опросы;
- участвовать в голосовании;
- создавать новые опросы;
- просматривать результаты;
- хранить пользовательские данные локально.
